# starry-night

Four animated dark themes for the Claude desktop app, switched with one command:

| Command | Look |
| --- | --- |
| `/skin starry-night` | Black space with realistic stars, a faint Milky Way band and the odd shooting star |
| `/skin void` | Pure black and white: a slow flight forward through the stars, thin white outlines on your messages |
| `/skin grape-night` | Purple-black with a grape accent and big soft orbs of light drifting slowly |
| `/skin rain-window` | Dark navy, raindrops sliding down a night window, heavily frosted panels |

Type `/skin` on its own to list them. Your choice is remembered for new sessions. Starry-night is the default.

The themes draw in the Claude desktop and mobile apps; the terminal shows no themes. The motion is light on the CPU, and with reduced motion turned on each backdrop shows as a still picture.

## Install

At the prompt of a terminal session:

```
/plugin install starry-night --marketplace 0xAvia/claude-themes
```

Answer `y` to add the marketplace, then pick a scope (the user scope is first; press Enter).

From a shell:

```
claude plugin install starry-night --marketplace 0xAvia/claude-themes
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `0xAvia/claude-themes`, then Add plugin.
